Publishing with a new GitHub username:
  - For a personal site, create a public repository named NEWUSERNAME.github.io
    (substitute your current GitHub username), unless you already have one.
  - Upload the six website files listed above to the repo root, not the ZIP.
  - Settings > Pages > Deploy from a branch > main > /(root) > Save.
  - Visit https://NEWUSERNAME.github.io/ after deployment.
  - To update later, edit the HTML file on GitHub, commit, and GitHub Pages republish.
  - Keep a local backup, or download a fresh ZIP after GitHub edits.
